# Contributing

1. Preserve component boundaries.
2. Add or update schemas before changing data contracts.
3. Add tests for behavioural changes.
4. Do not silently break canonical IDs.
5. Record provenance for imported material.
6. Keep simulation deterministic where determinism is specified.
7. Safety and compliance uncertainty must not be converted into approval.
8. Keep AI-provider integration replaceable.
