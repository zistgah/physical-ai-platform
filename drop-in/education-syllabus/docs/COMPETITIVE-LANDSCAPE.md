# Competitive and reference landscape

This is a capability comparison, not a claim that PAP already matches these products.

| Product / ecosystem | Strength to learn from | PAP opportunity / current gap |
|---|---|---|
| Moodle | Open LMS, course delivery, plugins, roles and assessment | PAP needs mature cohorts, gradebook, assignment, content authoring and admin workflows. |
| Open edX | Large-scale LMS/CMS, reusable learning sequences, assessment, analytics, LTI, open deployment | PAP should avoid duplicating a full mature LMS; focus on canonical engineering project graph and tool-rich STEM notebooks. |
| Jupyter / JupyterLite | Reproducible executable notebooks; browser/WASM route through JupyterLite | PAP needs a canonical notebook IR and safe runtime adapters; JupyterLite can be an adapter/reference, not source of truth. |
| MATLAB Live Editor | Code + narrative + equations + output + controls in a teaching artifact | PAP needs the same integrated explanation/experiment/result narrative, with replaceable compute backends. |
| Wolfram Notebook / Wolfram|Alpha | Symbolic and computational mathematics with dynamic exploration | PAP needs mathematics and symbolic tools that are connected to project requirements, simulations and evidence. |
| GeoGebra Classroom | Teacher-led shared interactive math activity and live classroom workflow | PAP needs teacher orchestration and learner response capture for all disciplines. |
| PhET | Research-informed interactive science/math simulations, activities and translations | PAP should support high-quality simulation pedagogy and localization; not every activity should be a code notebook. |
| Google Classroom / Canvas | Institutional LMS workflows and ecosystem integrations | PAP needs standards-based interoperability (LTI/CASE/QTI) rather than attempting to displace every institutional LMS immediately. |

## Position

PAP's differentiated proposition should be the integrated engineering-learning thread: a learner studies a concept, manipulates a model, runs a simulation, creates an engineering artifact, validates it, and links the resulting evidence to the same canonical project graph. Teacher, professor, lab assistant, parent and independent learner views are projections over that shared model.

The package does not yet provide a complete enterprise LMS, live classroom conferencing, gradebook, identity federation, LTI 1.3 service, CASE service, QTI engine, notebook kernel or production analytics warehouse. Those are explicit future integration/implementation areas.
