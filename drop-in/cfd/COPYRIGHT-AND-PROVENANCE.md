## Notebook provenance

Each notebook must preserve its notebook ID, version, author, copyright, licence, source repository, immutable commit SHA, dependency versions, runtime metadata and generated artifact hashes. Notebook output is untrusted until checked. Do not save API keys, personal data or credentials in notebook source or outputs.

## Simulation provenance

A result must bind to canonical subject IDs and a configuration revision, plus mesh, input, solver and output checksums. Capture exact solver distribution/version/build options, environment, hardware, dependencies, process exit code, convergence data and benchmark comparison. Unknown provenance remains unknown.
