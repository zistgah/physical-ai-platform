# Suite gaps

Iteration 44. Honest. No other organization is named.

## What this is

A systems-engineering graph with views. A solid is an entity. A feature is a relation. A volume is evidence. Samples are projects with parameters.

## What a suite has that we do not

| Domain | We have | A suite has | Depth |
|---|---|---|---|
| CAD | Mesh kernel, box B-rep, STL in and out | Half-edge, B-rep boolean with intersection, history that rebuilds a changed feature, viewport with selection | SHALLOW |
| Simulation | One integrator, a coupled step, fault domains | Multi-body dynamics, contact, hydrodynamics, aerodynamics | SHALLOW |
| Manufacturing | Work orders, a BOM, a meter and an invoice | Routing, capacity, quality holds, supplier graph | PARTIAL |
| Education | A course, lessons, board correlation by id | A curriculum that a board accepts, progress that a registrar trusts | PARTIAL |
| Compliance | A corpus, typed evidence binding | Applicability that a regulator accepts as binding | INFORMATIONAL |
| HIL | A fixed-step loop, a transport that holds without a device | A device on a bus, a deadline that a hardware clock enforces | ADAPTER |
| Proof | A prover for inequalities | A bound prover for the claims we make | ADAPTER |
| Fleet | Deployment records | An operations center with live state | RECORDS |
| Teleoperation | A session graph | A remote stack with latency and authority | GRAPH |
| UI | Pages that call modules | A workbench with selection, a feature tree, a viewport | LIST |

## What is not a bluff

The kernel is real. Typed entities, typed relations, provenance. Volume is the face integral. Evidence in a bad state holds. A claim without evidence holds. STL round-trips. Eleven samples load with the parameters given.

## What is a bluff if claimed

A sample is not a dynamics model. A fault domain is not a contact solver. A B-rep boolean is face classification, not an intersection tessellation. A viewport is a pixel buffer, not a selectable view.
