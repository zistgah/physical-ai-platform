# Iteration 21 Result

## Why standards said null null

137 of 164 records had a null layer and a null topic. The page printed both. 27 records had a null title and a null authority. The fields existed on other records under different names.

Every record now has a title, topic, layer, and authority. Title falls back to topic, then name. Layer falls back to category, then Global. Authority is inferred from the designation when the record has none.

## Automated compliance

An adopted standard is checked without a manual step. Missing required evidence HOLDs the compliance run and the gate. No adoption does not invent a hold. This is not a regulatory determination.
