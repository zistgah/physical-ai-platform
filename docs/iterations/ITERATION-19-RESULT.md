## Subtract

A triangle cutter in a hexagon subtracts. Volume is base minus cutter. The path is a profile boolean for any simple polygon, then a plane-clip fallback when sketches are absent. It is not a rectangular pocket constructor.

## CAD page

`/cad` is a workbench. You add points, extrude, subtract a cutter, and select from a feature tree. A canvas draws the sketch or the mesh. The canned plate demo is gone.
