# Iteration 17 Result

The domains outside CAD are implemented as working systems on the canonical graph.

## Built

- SIR runtime. `let`, `fn`, `if`, `for`, entity creation. An unbound name throws.
- MES. Work order on a machine. A step that requires inspection HOLDs until it passes. Completion links PRODUCES.
- MANUFACTURED_BY settled. A component is manufactured by a process.
- ERP. Issue HOLDs when stock is short. A successful issue decrements stock and rolls cost.
- LMS. A lesson HOLDs if the person is not enrolled. A course completes only when every lesson is done.
- Prover. Proves a weaker numeric bound. An unproved claim HOLDs.
- Multi-physics. Explicit thermal step coupled to strain. Temperature moves toward the boundary.
- Distributed runtime. A down node HOLDs. A live node runs the job.
- HIL loop. Fixed-step plant and controller. A missed deadline HOLDs.
- Fleet ops. Health rollup. A command without authority HOLDs.
- Teleop remote stack. No link, no command. Local e-stop kills the link.
- Cockpit. A checklist item HOLDs if the role lacks the authority. Complete checklist reaches S10.
- Standards binding. Project acceptance is not a regulatory determination. No evidence HOLDs.
- Workbench. `/workbench` shows the graph and can add a component.
