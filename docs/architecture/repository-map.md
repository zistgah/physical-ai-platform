# Repository Map

The repository is deliberately componentised.

`site/components/core` contains generic runtime primitives.

`site/components/graph` contains semantic graph functions.

`site/components/workbench` contains system composition.

`site/components/simulation` contains the simulator and reference components.

Domain components are isolated into safety, compliance, education, research,
manufacturing and teleoperation modules.

`data` is content, not application logic.

`schemas` are contracts.

`tests` validates component behaviour.

`sources` preserves provenance.
