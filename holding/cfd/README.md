# CFD package bundle 1.3.0

This bundle contains two distinct packages:

- `cfd/` - bounded 1D CFD reference solver, external backend catalogue, Colab notebook, job-envelope adapter, tests and full documentation.
- `extensions/scientific-backend-orchestration/` - separate reusable backend registry and execution-governance package.

Read `cfd/BUILD-ANALYSIS.md` first, then `cfd/ARCHITECTURE.md`, `cfd/BACKEND-INTEGRATION.md`, `cfd/TEST-MATRIX.md` and `cfd/STITCH-INSTRUCTIONS.md`.

No third-party CFD executable is bundled. No external solver is claimed as execution-tested. No platform integration is claimed.
