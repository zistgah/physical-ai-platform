# Security

Do not treat the browser simulator as a safety-certified control system.

Security vulnerabilities affecting command authority, configuration integrity,
firmware, simulation results, provenance, compliance state or safety logic should
be reported privately to the maintainers.

Physical deployment requires independent engineering and safety validation.
